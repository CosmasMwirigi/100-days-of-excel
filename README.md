# 100 Days of Excel

I'm learning Excel in public on my way to becoming a data analyst. After finishing the SQL basics ([100 Days of SQL](https://github.com/CosmasMwirigi/100-days-of-sql)), Excel is the next tool. Every day I study, take handwritten notes, and turn them into documentation and practice workbooks in this repo.

## Why I'm doing this

The job market is tough. Learning in public keeps me consistent and shows exactly what I know, one day at a time.

## Progress

## Repo structure

Each day has its own folder with:

- `README.md`: my notes for the day, written up properly
- `.xlsx` files: practice workbooks you can download and open
- `images/`: visual summaries
